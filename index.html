Configuración y guía

Conecta una base de datos para que Gabriel y Salma puedan guardar y ver los mismos recuerdos desde cualquier lugar.

Espacio compartido

Modo local

La sincronización usa Supabase con inicio de sesión individual. Cada cuenta debe estar autorizada para entrar al espacio de pareja.

Tu cuenta
Configura Supabase para iniciar sesión.
No compartan contraseñas. Cada uno entra con su propia cuenta. El acceso está limitado a los UUID añadidos a la tabla couple_members.
Cómo ponerlo en marcha

Guía para compartir a distancia

1

Publica la web. Sube index.html, config.js y la carpeta assets a GitHub Pages u otro hosting HTTPS.

2

Crea un proyecto Supabase. Ejecuta el archivo supabase_setup.sql desde SQL Editor.

3

Configura las claves. Copia Project URL y la clave pública a config.js o a los campos de arriba.

4

Crea las dos cuentas. Gabriel y Salma se registran con sus propios correos desde esta página.

5

Autoriza las cuentas. En Supabase Authentication > Users copia los dos User UID y añádelos a couple_members con el SQL de la guía.

6

Inicien sesión. Los recuerdos y fotos nuevos se sincronizarán con la misma base de datos.

Copias de seguridad

⇄

Exporta una copia JSON de tus recuerdos. En modo local puedes importarla en otro dispositivo; en modo compartido los datos viven en Supabase, pero conservar una copia sigue siendo buena idea.

Privacidad

Un espacio pensado para dos

El SQL incluido usa inicio de sesión y políticas RLS. Las fotos van a un bucket privado. No pongas la clave service_role en el sitio y no subas información íntima o sensible. Para permitir el acceso, añade solamente los dos UUID reales a couple_members.
